# Fixed Window Rate Limiting
- How many requests a client can make within a fixed time period or interval.

Example
- API allows 5 requests per minute per PI address 
- Window 1: 10:00:00–10:00:59       5 request       ✔️
- Window 2: 10:01:00–10:01:59       3 request       ✔️
- Window 3: 10:02:00–10:02:59       6 request       ❌


Weakness is that it allows traffic bursts at the boundary between two windows. 


```ts

import { Request, Response, NextFunction } from "express";

const WINDOW_MS = 60 * 1000; // 1 minute
const MAX_REQUESTS = 5;

type WindowCounter = {
  count: number;
};

const requests = new Map<string, WindowCounter>();

export function rateLimiter(
  req: Request,
  res: Response,
  next: NextFunction
) {
  const ip = req.ip ?? "unknown";
  const now = Date.now();

  // Identify the current fixed time window
  const windowId = Math.floor(now / WINDOW_MS);
  const key = `${ip}:${windowId}`;

  const current = requests.get(key) ?? { count: 0 };

  current.count++;
  requests.set(key, current);

  // Include limit information in the response
  res.setHeader("X-RateLimit-Limit", MAX_REQUESTS);
  res.setHeader(
    "X-RateLimit-Remaining",
    Math.max(0, MAX_REQUESTS - current.count)
  );

  if (current.count > MAX_REQUESTS) {
    res.setHeader("Retry-After", Math.ceil(
      (WINDOW_MS - (now % WINDOW_MS)) / 1000
    ));

    return res.status(429).json({
      error: "Too many requests",
      message: "Please try again later.",
    });
  }

  next();
}
```

```ts

import express from "express";
import { rateLimiter } from "./rateLimiter";

const app = express();

app.use("/api", rateLimiter);

app.get("/api/users", (_req, res) => {
  res.json({
    message: "Users fetched successfully",
  });
});

app.listen(3000, () => {
  console.log("Server running at http://localhost:3000");
});

```

One important improvement: clean up old counters

```ts
// Remove counters belonging to expired windows
setInterval(() => {
  const currentWindow = Math.floor(Date.now() / WINDOW_MS);

  for (const key of requests.keys()) {
    const windowId = Number(key.split(":").at(-1));

    if (windowId < currentWindow) {
      requests.delete(key);
    }
  }
}, WINDOW_MS);
```
