### ~={orange}1.  What are tags and attributes?=~

- **Tags**: Define elements (`<img>`, `<a>`)
- **Attributes**: Provide extra info
```html
<img src="image.jpg" alt="Image">
```

### ~={orange}2. What is a semantic tag?=~

Semantic tags clearly describe their meaning:
- `<article>`, `<section>`, `<nav>`, `<header>` 

### ~={orange}3. Difference between block and inline elements?=~

- **Block**: Takes full width (`<div>`, `<p>`)
- **Inline**: Takes only needed space (`<span>`, `<a>`)

### ~={orange}4. What is the difference between `id` and `class`?=~

- `id`: Unique (used once)
- `class`: Can be reused multiple times
### ~={orange}5. What is the difference between `<strong>` and `<b>`?=~

- `<strong>`: Semantic (important text)
- `<b>`: Just bold styling

### ~={orange}6. What is the difference between `<link>` and `<a>`?=~

- `<link>`: Connects external resources (CSS)
- `<a>`: Creates hyperlinks

### ~={orange}7. **What is the difference between `<div>` and `<span>`?**=~

| `<div>`                           | `<span>`                      |
| --------------------------------- | ----------------------------- |
| Block-level element               | Inline element                |
| Takes full width                  | Takes only needed width       |
| Used for larger layout structures | Used for small inline content |
