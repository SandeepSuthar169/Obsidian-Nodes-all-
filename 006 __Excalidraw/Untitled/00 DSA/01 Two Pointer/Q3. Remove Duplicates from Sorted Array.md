- The array is already **sorted**.
- This means duplicates will always be next to each other.
```txt
[1, 1, 2, 2, 3, 3, 4]
 ↑  ↑
duplicates are adjacent
```
- So we only need to compare the current element with the previous unique element.

---

```js
function removeDuplicates(nums) {
    if (nums.length === 0) return 0;

    let i = 1;

    for (let j = 1; j < nums.length; j++) {
        if (nums[j] !== nums[i - 1]) {
            nums[i] = nums[j];
            i++;
        }
    }

    return i;
}
```

 - ` nums[0] ` is always unique element. 
 
- **` i `** — slow pointer, tracks where the next unique element should go. 
- **` j `** — fast pointer, scans ahead to find the next unique element. 


