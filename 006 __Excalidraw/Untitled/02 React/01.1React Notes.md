## 1. JSX 

A React component is a function that return some JSX. ****

JSX is an extension to JavaScript that allow we to write HTML-like directly inside JavaScript code. 

React Development Server uses the following tools:
-  Babel to transpile the JavaScript code.
-  Webpack tool to merge the output JavaScript files into a single file called bundle.js

- But JSX cannot display a Boolean value (`true`, `false`), `null`, `undefined`:

```jsx
const App = () => {
  const name = 'John';
  const age = 25;
  const active = true;
  let jobTitle = null;

  return (
    <ul>
      <li>Name: {name}</li>   // Name: John
      <li>Age: {age}</li>    // Age: 25
      <li>Status: {active}</li>   // Status
      <li>Job Title: {jobTitle}</li>    // Job Title:
    </ul>
  );
};
```

##  3. State in React

State is data stored in a React component that changes over time and update the UI automatically 

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}
```
- `count` : current state value
- `setCount` : function to update state 

State hold data type
```jsx
useState(0);              // number
useState("Hello");        // string
useState(true);           // boolean
useState([]);             // array
useState({ name: "Ali" }); // object
```

- State changes are ~={orange}asynchronous =~

## 5. Event in React.

React Event is an action that occurs in the application such as a user clicking a button, typing, mouse movement or form submission in react app.

React events are written in camelCase ex `onClick`, `onChange` or `onSubmit`  

```jsx
import React, { useState } from 'react';

function ButtonClick() {
  const [count, setCount] = useState(0);

  const handleClick = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <p>You clicked {count} times.</p>
      <button onClick={handleClick}>Click Me</button>
    </div>
  );
}

export default ButtonClick;
```

### 7. JSX Key Prop

1. Rendering a list 
	- we need display a list of element or components from an array of data. so to do that we ca use the array `map()` method to transform an array of data into an array of components. 
	
```jsx
const App = () => {

  const names = ['Anthony Pham', 'Alex Johnson', 'Bob Climo'];

  const renderedNames = names.map((name) => {
	   return <li>{name}</li>;
  });

  return <ul>{renderedNames}</ul>;
};

export default App;


//output is

- Alex Johnson
- Bob Climo
```

2. What are keys.
	- `keys` ae special values that help react identify which items in a list changed , added and removed 
	
	###  Why are keys important?
	-  Identify items ~={orange}uniquely=~ 
	- ~={orange}update=~ only what ~={orange}changed=~
	- ~={orange} Avoid UI bugs=~ when list~={orange} order changes=~

```jsx
function List() {
  const fruits = ["Apple", "Banana", "Mango"];

  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  );
}
```

## React State-> 

State is data that belongs to a component and when state changes, React will re-render (update data in component ) and reflect the in UI with new info. 

- state  =  changing data the react keeps tract in. 

```js
import { useState } from "react";

function Counter() {
  // count = current value
  // setCount = function to update the value
  const [count, setCount] = useState(0);

  return (
    <div>
      <h1>You clicked {count} times</h1>

      <button onClick={() => setCount(count + 1)}>Click here </button>
    </div>
  );
}

export default Counter;
```
